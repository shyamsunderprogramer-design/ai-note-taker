# AI Note Taker — Android native project (Fix #27)

This folder is the **Android native scaffold** for the React Native app
at `mobile/`. It was added in 2026-06-06 alongside the equivalent iOS
scaffold at `mobile/ios/`.

## What's here

- `build.gradle` (root) — top-level Gradle config (SDK versions, repos)
- `settings.gradle` — registers `:app` and the React Native Gradle plugin
- `gradle.properties` — JVM args, AndroidX flag, RN architecture toggles
- `app/build.gradle` — the `com.ainotetaker` app module
- `app/src/main/AndroidManifest.xml` — declares the app, permissions, MainActivity
- `app/src/main/java/com/ainotetaker/MainActivity.kt` — RN host activity (Kotlin)
- `app/src/main/java/com/ainotetaker/MainApplication.kt` — RN host application
- `app/src/main/res/values/strings.xml` — app name string
- `app/src/main/res/values/styles.xml` — AppCompat theme
- `app/proguard-rules.pro` — release-build minification rules

## What's NOT here

- `gradle/wrapper/gradle-wrapper.jar` — generated by `gradle wrapper`
- `gradlew` / `gradlew.bat` — generated by `gradle wrapper`
- `app/build/` — Gradle build output
- `app/debug.keystore` — generated by `keytool -genkey ...` or auto-generated
  by `./gradlew assembleDebug` if missing

## Building

From the repo root:

```bash
npm --workspace ant-mobile run android
```

Or directly:

```bash
cd mobile/android
./gradlew assembleDebug          # produces app/build/outputs/apk/debug/app-debug.apk
# or
./gradlew installDebug           # installs onto a connected emulator/device
```

If `./gradlew` doesn't exist yet, generate the wrapper:

```bash
cd mobile/android
gradle wrapper --gradle-version 8.3
```

## Notes

- **Package name**: `com.ainotetaker` (RN default — change in `app/build.gradle`
  and rename the `com/ainotetaker/` source folder if you go to the Play Store)
- **New Architecture** (Fabric + TurboModules): enabled in `gradle.properties`
  via `newArchEnabled=true` — RN 0.73 default
- **Hermes**: enabled in `gradle.properties` via `hermesEnabled=true`
- **Java/Kotlin**: Kotlin 1.9.22 (`kotlinVersion` in root `build.gradle`)
- **SDK levels**: min 23 (Android 6.0), target 34 (Android 14), compile 34
- **NDK**: 26.1.10909125 (only used if you ship C++ codegen modules)

## Permissions in the manifest

- `INTERNET` — to reach the FastAPI backend
- `RECORD_AUDIO` — for in-meeting transcription
- `WAKE_LOCK` — to keep the device awake during long captures
- `VIBRATE` / `RECEIVE_BOOT_COMPLETED` / `POST_NOTIFICATIONS` — for push
  notifications (the `react-native-push-notification` dep)

`usesCleartextTraffic="true"` is set so the dev Metro bundler on
`http://10.0.2.2:8081` (Android emulator → host machine) works in debug
builds. Remove for production.
