# AI Note Taker — iOS native project (Fix #27)

This folder is the **iOS native scaffold** for the React Native app at
`mobile/`. It was added in 2026-06-06 alongside the equivalent Android
scaffold at `mobile/android/`.

## What's here

- `AI Note Taker.xcodeproj/project.pbxproj` — Xcode project file (autogenerated
  by `react-native init`; this is a minimal hand-written version that
  references the same source files)
- `AI Note Taker/AppDelegate.h` / `AppDelegate.mm` / `main.m` — RN 0.73 entry point
- `AI Note Taker/Info.plist` — iOS app metadata
- `AI Note Taker/LaunchScreen.storyboard` — splash screen
- `AI Note Taker/Images.xcassets/` — asset catalog (AppIcon placeholder)
- `Podfile` — CocoaPods manifest (Hermes is the JS engine)

## What's NOT here

- `Pods/` — generated by `cd mobile/ios && pod install`
- `build/` — Xcode build output
- `*.xcworkspace` — generated by CocoaPods (commit `AI Note Taker.xcworkspace`)
- `AI Note Taker.xcuserstate` — generated by Xcode on first open

## Building

From the repo root:

```bash
npm --workspace ant-mobile run ios
```

Or, more directly:

```bash
cd mobile/ios
pod install                                    # one-time, or when Podfile changes
open "AI Note Taker.xcworkspace"               # launches Xcode
# …or…
xcodebuild -workspace "AI Note Taker.xcworkspace" -scheme "AI Note Taker" -configuration Debug -sdk iphonesimulator
```

## Notes

- **Bundle ID**: `org.reactjs.native.example.AINoteTaker` (RN default — change
  in Xcode before App Store submission)
- **Deployment target**: matches the `min_ios_version_supported` constant
  resolved by `react_native_pods.rb` (currently iOS 13.4 for RN 0.73)
- **Hermes**: enabled in Podfile — RN 0.73's default
- **App Transport Security**: `NSAllowsArbitraryLoads` is `false` in production;
  `NSAllowsLocalNetworking` is `true` so the dev Metro bundler on `localhost`
  works in debug builds

## When the project file gets stale

If you `npm upgrade react-native`, run `pod install` from this folder to
refresh the native deps. If you add new Swift/ObjC source files, regenerate
`project.pbxproj` by opening Xcode and dragging them into the project
navigator — hand-editing pbxproj is fragile.
