  {{- if .Values.sealedSecret.enabled }}

  SECRETS — IMPORTANT
  ───────────────────
  The SealedSecret manifest is included but contains no encrypted data
  yet (see k8s/helm/backend/templates/sealedsecret.yaml). Until you
  populate it, the deployment will be missing DATABASE_URL, ENCRYPTION_KEY,
  and the AI provider API keys, and will fail its readiness probe.

  To populate the SealedSecret:
      1. Install kubeseal:
            brew install kubeseal                                # macOS
            # or: https://github.com/bitnami-labs/sealed-secrets#installing
      2. Create a regular Secret and pipe through kubeseal:
            kubectl create secret generic {{ .Values.sealedSecret.name | default "ant-secrets" }} \
              --from-literal=database-url='postgres://user:pass@host:5432/db' \
              --from-literal=encryption-key='$(openssl rand -hex 32)' \
              --from-literal=openai-api-key='sk-...' \
              --from-literal=anthropic-api-key='sk-ant-...' \
              --from-literal=google-api-key='...' \
              --from-literal=neo4j-password='...' \
              --dry-run=client -o yaml \
            | kubeseal --format yaml > /tmp/ant-secrets.sealed.yaml
      3. Paste the resulting encryptedData into
         k8s/helm/backend/templates/sealedsecret.yaml (replace the
         empty `{}` on the last line of spec).
      4. Re-run `helm upgrade`.
  {{- end }}
