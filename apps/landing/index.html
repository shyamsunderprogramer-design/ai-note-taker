A few things to know

Good questions.
Clear answers.

More detail lives in the documentation.

Is ANT free to use?

ANT is free, open-source software under the MIT license. Local models run on your hardware. If you use a cloud AI provider, that provider may charge for API usage through your own account.

Does everything stay on my computer?

In the default local desktop setup, speech transcription runs on your computer. You can also use local Ollama models. Cloud AI sends selected context to external providers. A remotely hosted backend processes and stores its data on that server, so the browser app should not be treated as entirely local.

Do I need an API key or a developer setup?

The desktop download includes the Python runtime. You don’t need Python or Node.js installed separately. For local AI, install Ollama and download a model. For cloud AI, add a supported provider’s API key in Settings. Transcription models also need to be downloaded.

Why does my Mac show a verification warning?

The current Mac release is signed ad hoc, without Apple Developer ID notarization. If you trust the official download and its checksum matches, follow the first-launch instructions to approve ANT in System Settings → Privacy & Security. Microphone and screen recording permissions are separate.

How is the browser app different?

The browser shares ANT’s web interface and requires a running backend. The desktop app adds native window controls, tray access, global shortcuts, and platform-specific capture features. Browser permissions and supported capture options differ by browser.

Can I use ANT offline?

A local desktop workflow can run without cloud AI after its required models and dependencies are downloaded. Ollama and the local backend must be running. Cloud models and hosted backends require an internet connection.

Where can I get help or contribute?

Start with the troubleshooting guide. You can report a reproducible problem on GitHub Issues or explore the source and contribution guide. Keep API keys, private recordings, and personal notes out of bug reports.
