# Model Comparisons — April 2026

This subfolder contains historical model-comparison and task-assignment documents from April 2026, when the project was being planned in parallel across three AI models:

- **KIMI-K2.5** — database & complex features
- **MINIMAX-M2** — frontend, testing & DevOps
- **GLM-5.1** — backend security & API hardening

These documents are **historical** — they were planning artifacts, not current documentation. They were moved here from the `docs/` root on 2026-06-05 during the project audit/reorganization to make the main docs folder easier to navigate.
