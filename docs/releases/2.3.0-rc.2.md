# ANT 2.3.0-rc.2 — desktop login and capture fixes

This testing candidate fixes login persistence and recording/capture failures
reported in `v2.3.0-rc.1`. The older downloads do not contain these fixes.

## Remember me

- Checking Remember me keeps the login across app restarts, until the session
  expires or is revoked. The default refresh-token lifetime is seven days.
- Leaving it unchecked keeps the desktop login in memory until ANT quits.
  Browser logins use tab session storage. Merely hiding the desktop window
  does not quit ANT.
- Desktop remembered sessions use Electron's OS-backed `safeStorage` encryption.
  If a secure key store is unavailable, sign in with Remember me unchecked.
- A fresh sign-in is required after upgrading from the old username-only
  checkbox. Passwords are not stored by this feature.
- Expired access tokens renew automatically while the refresh session is valid.
  Signing out revokes the session on the backend when it is reachable and
  always removes the local session. Signing in on another device also revokes
  the previous session.
- Packaged desktop backend signing keys are generated once in the app's private data
  directory so restarting the backend does not invalidate every login.

## Audio and screen context

- The Mac screen-capture helper is compiled during packaging and included in
  the app. Installing Xcode or Swift on the user's Mac is unnecessary.
- Ordinary typed or spoken questions can continue without an optional screen
  capture, with a visible text-only notice. A question that explicitly needs
  the screen still requires a screenshot; ANT must not invent screen contents.
- A late recording-stop event cannot consume another recording's audio or stop
  its microphone stream. Brief empty recordings show a retry hint instead of
  an incorrect permission error.
- macOS permissions still apply. Microphone access and Screen & System Audio
  Recording are controlled in System Settings → Privacy & Security. ANT cannot
  enable those permissions for the user. These changes do not add Apple
  notarization to the existing unsigned release.

## Downloads and installation

Download the installer for your system and compare its SHA-256 with
`SHA256SUMS.txt` from the same release:

| System | File |
| --- | --- |
| Windows x64 installer | `ANT-Setup-2.3.0-rc.2-win-x64.exe` |
| Windows x64 portable | `ANT-2.3.0-rc.2-win-x64.exe` |
| Apple Silicon Mac | `ANT-2.3.0-rc.2-mac-arm64.zip` |
| Intel Mac | `ANT-2.3.0-rc.2-mac-x64.zip` |
| Linux x64 | `ANT-2.3.0-rc.2-linux-x86_64.AppImage` or `ANT-2.3.0-rc.2-linux-amd64.deb` |

Quit ANT before replacing the app. macOS 14 or newer is required; extract the
Mac ZIP and move the app into Applications. Back up existing data before testing.
Data stored inside an older installation's application resources is not migrated
automatically. Local models and API credentials are not included.

These builds use ad hoc signing on macOS and have no Apple notarization or
Windows publisher certificate. OS developer-verification warnings can still
appear. Microphone and screen-recording permissions require your approval.

## Validation

Run the web and Electron unit suites, backend authentication tests, and
`e2e/tests/remember-me.spec.js`. Packaging additionally runs the bundled Mac
helper's `--self-test` and verifies its code signature. This self-test loads
the executable without capturing a screen or claiming capture permission.

See [Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)
for the platform-specific protections and Linux key-store requirements.
