# ANT 2.3.0-rc.1

Testing prerelease from the verified `ux-sprint` application source. This candidate includes the recent live-assistant, history, authentication and dependency fixes. It does not replace the stable release automatically.

## Changes

- Live assistance retains conversation and follow-up context while listening continues. History includes the human conversation transcript.
- Hardened authentication on interview and résumé routes, upload handling, outbound Jira requests and sensitive logging.
- Updated dependencies and corrected provider-status checks, failed graph connection cleanup and speaker-turn transcription.
- Removed fabricated success responses from legacy CRM writes. Those writes report unavailable until real provider integrations are implemented.
- Desktop packaging uses a checksum-pinned, self-contained Python 3.12 runtime. Native builds cover Windows x64, Linux x64, Apple Silicon and Intel Mac.
- Packaged storage uses a writable user-data location rather than writing into application resources.

These builds have no Apple Developer ID notarization or Windows publisher certificate. macOS binaries are signed ad hoc. Installation may require the operating system's explicit approval for an unverified developer. SHA256SUMS.txt covers the exact downloadable files.

## Verification and limits

The base application passed hosted CI, 1,645 backend tests and 56 Chromium/Firefox tests. Its CodeQL listing had no open findings after fixes and nine documented false-positive dismissals. Base npm and Python dependency audits were clean. Release packaging adds native bundled-runtime, registration and login checks; results are recorded in the release checkpoint.

This is a testing candidate, not a claim that every feature or operating-system integration is validated. Real microphone/system-audio permissions, model downloads and live-provider latency require testing on the target device. Local models and API credentials are not included. Screen-capture protection depends on the OS and capture method and does not guarantee invisibility.

Repository `main` still has unresolved dependency alerts and an unrelated Git history. Cloud-template, low-severity scanner and optional voice-runtime reviews remain pending; these templates and optional downloaded runtimes are not certified by this release. Legacy CRM writes remain unavailable. Back up existing application data before testing a prerelease; the candidate does not migrate data out of an older app installation's internal resources automatically.
