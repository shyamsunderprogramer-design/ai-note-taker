## What's in this folder

Superseded or otherwise-historical docs. They are kept here for
reference but should not be updated. If you need to make a
change based on an archived doc, write a new doc in the
appropriate role's folder.

## How a doc gets archived

A doc moves to `archive/` when:

- It's been superseded by a newer doc in a role folder
- The feature it describes has been removed
- The competitor analysis is no longer current

The archived doc keeps its original filename; the moved file
gets a one-line note in `CHANGELOG.md`.
